# Triple Espresso

Projeto com enfase no uso de FLEXbox, método BEM e CSS/HTML avançado.
Criação de uma págino do zero, desde o cabeçalho, implementar vídeos na página, uso de forms e criação do rodapé.

Pontos a melhorar:

-otimizar mais o uso da FLEXbox;
-melhorar o uso de raciocínio lógico para facilitar organização dos elementos;
